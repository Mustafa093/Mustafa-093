# 🦉 مغامرة الأرقام

تطبيق ويب تفاعلي لأطفال الصف الأول لتعلم العد التصاعدي والتنازلي والأعداد الزوجية والفردية.

## التمارين

- **ترتيب الأعداد** — سحب وإفلات الأرقام لترتيبها تصاعديًا أو تنازليًا.
- **أكمل التسلسل** — إكمال الأرقام الناقصة في سلسلة عددية.
- **زوجي أم فردي** — سحب وإفلات الأرقام إلى السلة الصحيحة (زوجي/فردي).
- **لعبة التوصيل** — الربط بين كل رقم وما يناسبه (نوعه أو الرقم التالي له).

يتضمن التطبيق نظام نجوم، تشجيعًا صوتيًا وبصريًا (تميمة وتأثير احتفال)، ومستويات صعوبة (حتى 10 / 20 / 50)، ويعمل بشكل كامل على الأجهزة اللوحية والهواتف عبر اللمس.

## التشغيل

لا حاجة لأي أدوات بناء. يكفي فتح `index.html` مباشرة في المتصفح، أو تشغيل خادم ثابت بسيط، مثلاً:

```bash
python3 -m http.server 8000
```

ثم فتح `http://localhost:8000` في المتصفح.
